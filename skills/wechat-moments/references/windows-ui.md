# Windows 微信桌面操作

优先用环境提供的桌面控制工具。没有专用工具且允许本地自动化时，可使用 PowerShell/.NET 截图与 Win32 输入，先查看界面再操作。不要读取微信私有数据库、令牌或进程内存发帖。

Windows 桌面自动化注意事项：

- 高 DPI 下逻辑坐标与截图像素可能不同。自动化进程在截图、定位窗口和输入前采用一致的 DPI 感知模式，例如 Win32 的 SetProcessDPIAware()；之后重新截图定位。不要复用历史坐标。
- 根据现场核实进程、主窗口、账号。激活、恢复或调整窗口后等待并截图；移动鼠标后略等再按下与松开，避免遗漏输入。
- 多条很长的绝对路径可能在文件名输入框被截断，可能导致只上传部分照片。先进入精选目录，再输入带引号的短文件名，例如："01.jpg" "02.jpg" … "09.jpg"。检查输入及实际上传数量。
- 粘贴前确认目标控件有焦点。对话框加载或关闭时，不盲目连续输入多步操作。
- 图片异步处理，暂时只有少量图片不等于结束。等待并再次查看，仍不完整才修正。
- 取消编辑可能出现“将此次编辑保留？”；处理后再继续。不要丢弃用户已有草稿，只可丢弃本次新建且需要重做的内容。
- 发布后刷新，看到本账号对应配文和照片的新条目才报告成功。提交结果不明时检查本账号相册，避免重复发布。

以上是操作经验，不保证未来版本界面不变。不要硬编码历史坐标、窗口句柄、账号名或原始照片路径。
